    Your agents run on this phone too, so the agent tools you use (for example Claude Code) must be installed in Termux, and the phone should stay on charge. A computer is faster for heavy work.

    The Wireless debugging address is this phone. It only works as Automa's address when Automa runs on this phone (above). Automa on a computer prints its own address, usually ending in :3100.
    Where do I find the address?
    1. On your computer, start Automa so other devices can reach it: npx paperclipai onboard --bind lan (same Wi-Fi) or --bind tailnet (Tailscale).
    2. Enter the address it prints, such as 192.168.1.20:3100 or your Tailscale name. The phone and the computer must be on the same Wi-Fi or tailnet.
    3. If the server rejects this phone's address, allow it with npx paperclipai allowed-hostname <address>. For access from anywhere, put Automa behind HTTPS.
