Connect to your Automa server

Automa runs on your computer or a server you control. This app is your remote for it: tasks, approvals, agents, and files.

    Where do I find the address?
    1. On the computer running Automa, start it with network access: npx paperclipai onboard --bind lan (same Wi-Fi) or --bind tailnet (Tailscale). You will sign in with the account it creates.
    2. Enter the address it prints, such as 192.168.1.20:3100 or your Tailscale name.
    3. If the server rejects this phone's address, allow it with npx paperclipai allowed-hostname <address>. For access from anywhere, put Automa behind HTTPS.
