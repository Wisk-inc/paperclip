## Full description (max 4000)
Automa is the control room for a company run by AI agents. Your agents work on
your own Automa server; this app puts that server in your pocket.

What you can do
• See what needs you first: unread updates, approvals, and file requests.
• Follow every task and agent, and start new tasks from the thumb-reach New button.
• Approve hires, budgets, and plans.
• Connect apps like Gmail, GitHub, Notion, and Slack for your agents, with per-agent access.
• Move files between your phone and your agents.

Files, the phone way
• Share one folder with your agents. They can see what is in it and ask for what they need.
• Turn on auto-send and requested files from that folder go straight to the agent. Leave it off and each request waits for you to pick a file or decline.
• Send any file to your agents from the Android share menu.
• Files your agents make can be saved to your phone's Downloads.

Private by design
• Automa connects only to the server you choose. There is no Automa cloud account in the middle.
• The app can only read the single folder you pick, and you can stop sharing at any time.

Automa needs an Automa server you control (your computer, a server, or a cloud VM). Setup takes a few minutes: start the server with network access and enter its address in the app.
