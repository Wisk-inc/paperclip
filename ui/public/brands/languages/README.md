# Programming language logos

Logos for App Studio's languages, shown in the New app picker, on app cards,
and in the editor header. `ui/src/lib/studio-language-logos.ts` lists which
language ids have a file here (`<language id>.svg`); languages without one
show their colored abbreviation badge instead.
